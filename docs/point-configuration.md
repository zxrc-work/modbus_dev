# 独立测点与周期预算

## 配置范围

配置版本为 `schema_version=4`，每个会话最多 8 个测点，至少启用一个。连接、站号、访问权限及周期为会话级设置；地址、类型、字节序和操作/区域分别保存在每个测点内。
界面去掉全局默认编码和全局操作。测点通过 1～8 紧凑数字标签切换，一次显示一个编辑页，不再提供展开/收起。
禁用点仍可查看，参数保留并灰显，启用开关仍可操作；不占地址、不产生请求、不计预算。

- 32 位类型 `float32/int32/uint32` 默认 `B1234`，16 位类型默认 `B12`；界面显示为 `1234` 和 `12`。
- 改变类型时保留仍兼容的排列；跨位宽的不兼容排列改为新类型默认值。
- `byte_order` 在新配置中逐点明确保存，不再继承全局值。

## 主站：逐点操作

`points[].operation` 可选 `read-holding`（FC03）、`read-input`（FC04）、`write-single`（FC06）或 `write-multiple`（FC16）。
区域由操作推导，不提供相互矛盾的区域/功能码组合。

读取点的数值来自对端，不生成本机源值。写入点使用自己的 `source`，并可设置 `readback_every`：0 不读回，N 表示每 N 个周期用 FC03 读回该点。
同一点保留一个主要操作；写后读回不是独立调度任务。FC06 只允许 16 位点，32 位点使用 FC16，不再自动拆成两笔写入。

请求按功能码及读回频率分组，同组地址连续时合并；不跨未配置或禁用地址，不跨寄存器区。不同类型、排列可以在同一个读取区间内逐点解码。
FC06 始终逐寄存器发送。各点共用一个周期；最忙周期的请求计划用于预算，不能把低频读回平均摊薄。

## 从站：逐点区域

TCP 与 RTU 共用独立寄存器区行为，每个点只属于 `points[].area` 指定的一个区域：

| 区域 | 数值设置 | 主站访问 |
| --- | --- | --- |
| `holding` 保持区 | `source.kind=constant` 和 `source.value` 为初始值；之后保留主站写入 | FC03 读取；读写权限下允许 FC06/16 写入 |
| `input` 输入区 | 按 `source` 和数据更新周期持续产生数值 | FC04 读取，不受主站写入影响 |

两区地址空间独立，可以在同一地址定义不同类型、排列和数值；同一区域内的测点不允许重叠。不创建未配置区域的镜像。
保持区在同一会话重连时保留，新会话重新初始化。TCP/RTU 从站缺少访问权限字段时默认只读。
RTU 接受原始单寄存器读写；TCP 读取需覆盖完整测点边界。FC16 全范围合法才更新，不允许非法请求部分修改。

## 周期硬下限与黄色预警

周期范围为 **20～60000ms**。主站界面称“通信轮询周期”，控制一轮测点读写；
从站称“输入区数据更新周期”，所有启用的输入区测点共用，不更新保持区，也不决定主站读取频率。
主站先生成实际请求计划，再计算线路耗时，所有时间单位为毫秒：

```text
t = 1000 × (起始位 + 数据位 + 校验位 + 停止位) / 波特率
g = max(1.75, 3.5 × t)
T交易 = 全部请求和正常响应字节数 × t + (2 × 交易数 − 1) × g
T线路 = T交易 + g
最低周期 M = max(20, ceil(T线路 + 10))
黄色线 W = ceil(1.2 × M)
```

10ms 是每个完整周期总共一次的流程预留，不按测点数或请求数重复累加；整数毫秒上取整。周期内的通信预算 B 还需满足 `T交易 < B ≤ 周期 − g`。
10ms 余量在整个周期内统一预留，不在内部通信预算中再次累加。

- 周期小于 M 或其他配置校验失败：红色，禁用启动，CLI/worker 同样拒绝。
- 周期达到 M 但小于 W：黄色，允许启动。
- 周期达到 W：不触发余量警告，不代表硬实时或保证设备响应。

界面同步显示启用点数、最忙周期请求数、线路耗时、修正最低周期、黄色线与当前周期。运行中仍按实际剩余预算检查，过期槽位不追赶突发。

## 配置兼容与启动重置

任务 JSON 只支持显式 `schema_version=4`。版本 1～3、未知版本或缺少版本号的文件提示“不兼容，请重新配置”，不迁移、不覆盖导入文件。旧版 `addresses/source`、全局操作、全局编码与全局读回字段不再接受。

界面自动保存使用独立的 `config_compat_version`，由 `ui.defaults.SETTINGS_COMPAT_VERSION` 定义：

- 同兼容版本：恢复通信设置、未完成草稿、语言及结果父目录，不自动启动通信。
- 兼容标记缺失或不匹配：在初始化语言、解析草稿之前，直接以默认通信设置和跟随系统语言原子覆盖旧设置，不尝试迁移。
- 重置时保留原结果父目录路径；不删除、搬移或清理任何已有结果目录和文件，不自动创建该目录。
- 写入失败时使用内存默认设置并报告错误，原设置文件保持完整。
- 只有保存内容发生不兼容变化时才递增兼容版本，不随普通软件补丁版本递增。本版本之前没有兼容标记的自动保存文件均按重置规则处理。

输入区与保持区使用各自的测点身份记录实际 TX/RX、数值表及曲线，不按相同地址跨区解码。TCP 读响应完整交给 socket 后才记录 TX 数值，排队不等于已发送。
