# Modbus Dev 需求说明

日期：2026-10-22。状态：首版需求基线；实现进度见 implementation.md。

## 1. 定位与交付

独立的 Modbus 通信测试、模拟、数据回放与诊断软件，仓库为 `D:\zx-code\modbus_dev`。
核心能力同时用于无界面 CLI 和可选桌面 GUI。单次只运行一个会话，不设计多会话管理系统。
软件作为独立产品安装、运行和验证，仅依赖明确声明的第三方库。功能范围限定为通用 Modbus 通信、模拟、回放和诊断。

后台运行指普通 CLI 进程；不提供 Windows 服务、开机自启、远程控制 API。
第一版不提供 TCP 主站、任意寄存器编辑和更多功能码，作为后续独立需求。

## 2. 第一版功能

| 编号 | 能力 | 边界 |
|---|---|---|
| F01 | RTU 主站 FC16 发数 | 持续发数、严格回放两种策略，FC03/04 读回验证；明确区分 ACK 与业务验收 |
| F02 | RTU 只读从站 | 响应 FC03/04；不接受写入；数据时钟独立于轮询频率 |
| F03 | TCP 只读从站 | 保留现有合成点表和延迟模拟；PR2XXG、ADAM 是测试预设，不是实机认证 |
| F04 | 数据源 | 当前阶段采用常量、正弦；DYN 与 CSV 离线接入推迟至 GUI 之后，届时明确格式、原时间、质量和通道标识 |
| F05 | 点表与编码 | 零基地址、完整 float32 点、四种已有字节排列；拒绝重叠、越界、非有限值 |
| F06 | 会话配置 | 版本化 JSON；CLI/GUI 共用校验；运行期间配置不可变，修改后重启会话 |
| F07 | 结果与日志 | 配置快照、结构化日志、原始收发证据、统计摘要及 CSV 导出 |
| F08 | 桌面界面 | 配置、启动、停止、状态、统计、错误/警告和结果位置；不得在 UI 线程执行通信 |
| F09 | 无界面运行 | 统一 CLI，支持退出码和结构化输出，正常停止时释放资源并完成摘要 |

坏质量 DYN 点不伪装为当前好值：主站跳过相应点，从站撤下相应点的可读值。
实施顺序为 TCP 只读从站、RTU 只读从站、GUI；DYN/CSV 离线输入暂缓，不作为从站或 GUI 的交付前提。
不自动循环 DYN、拼接时间缺口或倍速回放；以后增加时必须定义其时间和质量语义。
严格回放遇到交易失败或落后完整周期时失败退出；持续发数记录异常、跳过失效槽位并按策略重连。

## 3. 性能和稳定性

- P01：100/200 ms 发数采用单调时钟和绝对槽位，不使用“交易完成后 sleep 一个周期”。
- P02：交易总预算包括准备、静默等待、写入和应答；不得以隐式重试突破槽位预算。
- P03：按波特率、校验位、停止位和所有交易计算线路预算；多组写入/读回不能套用单次交易预算。
- P04：收到迟到数据后保守重启帧间静默；连续噪声等待有上限；剩余预算不足则跳过，禁止追赶突发。
- P05：保留 Windows 写入路径不引入 50 ms flush 轮询的回归要求；不能把 write 返回当作物理发送完成。
- P06：RTU 无事务号，超时后的同地址 ACK 不能恢复成确定成功，除非有明确可靠的重新同步依据。
- P07：串口错误不得导致主循环退出失控；持续模式有节制重连，严格模式明确失败。
- P08：GUI 刷新不高于 5 Hz，日志批量追加并限制保留条数；通信路径不调用 UI、磁盘 flush 或阻塞日志消费者。
- P09：日志队列和 UI 缓冲均有界；溢出可见并计数，结果标注证据不完整。日志写入失败不能报告运行成功。
- P10：所有阻塞 I/O 有期限；停止不等待一个完整长回放，正常停止需关闭串口、socket、子进程和日志。

100 ms 是目标调度周期，不承诺操作系统或 USB 串口硬实时。验收必须报告均值、P95/P99、最大迟到、
超时、跳槽和日志丢失，不能只看平均频率。默认调度容差为周期的 10%，可配置；容差内正常，超出告警，告警本身不停止任务。应答超时独立配置。

## 4. 可观测性

每条事件包含 UTC 时间、单调时间、会话 ID、事件代码、级别、阶段和结构化详情。
通信故障包含端口、设备地址、功能码、寄存器范围、超时预算、异常类型/码、重试状态和关联报文。
GUI 展示可理解的信息及处理建议；完整堆栈进入文件详情，敏感配置不直接记录。
相同告警 UI 可合并计数，但保留首次/末次时间；合并与原始证据丢失必须区分。
原始串口数据只称为驱动交付/提交证据，不称为物理线时间。

## 5. 兼容与独立交付

采用跨平台源码；Windows 发布包优先，麒麟 CLI 必须验证。GUI 不人为排除 Linux；Qt 依赖满足时可运行。
不同系统和 CPU 架构分别验证/打包。不承诺未验证的麒麟 GUI 环境。
不为 Python 3.7 维护兼容层，也不无故抬高最低版本；最低版本由选定依赖决定并记录。
CLI 安装不依赖 Qt。源码安装和独立桌面包共用业务代码，不强制使用 Cython。

提供统一 CLI 和可选桌面入口，共用配置模型和运行逻辑。安装包、运行配置和测试数据均有明确边界，验收可独立复现。

## 6. 完成标准

配置校验、调度、异常、停止、日志背压具有确定性测试；保留独立编码对端和固定报文样例。
Windows 虚拟 COM、Linux PTY、物理串口及标准 Modbus 设备验证分别记录，模拟测试不能替代物理串口验收。
100 ms 正常/迟到/超时/重连/持续噪声/日志压力场景均验证；GUI 开关前后对照调度统计。
独立安装后 CLI 可运行；可选 GUI 缺失不影响 CLI。
