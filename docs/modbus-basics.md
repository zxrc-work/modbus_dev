# Modbus RTU 基本概念

寄存器都在从站：输入寄存器由从站内部更新，主站只读；保持寄存器既可由从站内部更新，也可由主站按设备权限读写。

## 主从角色与权限

主站主动发起请求，从站处理请求并应答。同一条 RTU 总线上只运行一个主站。

| 配置 | 含义 |
| --- | --- |
| 主站只读 | 仅发送读取请求 |
| 主站读写 | 可发送读取或写入请求，具体由所选操作决定 |
| 从站只读 | 允许主站读取，拒绝主站写入 |
| 从站读写 | 允许主站读取及写入保持寄存器 |

主站读取时，测点地址指定要读取的对方地址；从站的测点配置定义本机对外提供的地址和数据。

## 寄存器区与功能码

实际设备的数据用途、地址和可写权限以厂家点表为准；“保持”不保证掉电保存。

| 功能码 | 操作 | 寄存器区 |
| --- | --- | --- |
| FC03 | 读取 | 保持区 |
| FC04 | 读取 | 输入区 |
| FC06 | 写入单个 16 位寄存器 | 保持区 |
| FC16 | 写入多个 16 位寄存器 | 保持区 |

FC04 没有写入功能。从站选择“读写”权限，也不允许主站写入输入区。

## 地址与本软件行为

保持区和输入区是独立区域，各自从地址 0 开始。FC03 + 地址 0 访问保持区地址 0，
FC04 + 地址 0 访问输入区地址 0。本软件使用零基地址；一个 float32 测点占同一区域内两个连续寄存器。

本软件 RTU 从站的保持区由首个数据源快照初始化，之后保留主站写入值；输入区按周期生成配置的常量或正弦波。
例如，FC16 向保持区写入 1.25 后，FC03 可读回 1.25，FC04 读取的输入区波形不受影响。

两机写入测试应配置为“主站读写 + FC16”和“从站读写”，写后读回使用 FC03。
具体步骤见 [RTU 寄存器读写与实时监视](rtu-register-monitor.md)。
