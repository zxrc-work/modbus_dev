# 实施记录

## 当前状态：M3.2 RTU 只读从站已实现，串口环境验收待完成（2026-10-22）

- RTU/TCP 共用 ReadOnlyRegisters、快照、数据时钟、SessionRunner、停止、日志与摘要。CLI `run` 支持 `rtu-slave`。
- RTU 复用 PyModbus CRC/帧/PDU 编码和既有 pySerial 打开逻辑；接收缓冲 256 字节，按驱动静默划帧，坏 CRC/短帧/超长帧整帧丢弃。
- 广播、其他站号不响应；FC03/04 可读，其他请求功能码异常 01；读数量、空洞和半点检查沿用 TCP 规则。
- 连续策略 I/O 故障/短写至少间隔 1 秒重连；严格策略失败退出。停止支持接收、持续噪声、半帧和重连等待。
- 本轮 Windows/Python 3.12 下 70 项测试通过：包含独立 CRC 固定报文、分段、未知功能码、广播、噪声恢复、四种字节序、正弦、数据时钟、停止和故障策略。测试使用模拟串口与确定性时钟。
- 当前环境未枚举到串口；本轮没有执行虚拟 COM、Linux PTY 或物理 RS485 验收，不以模拟测试代替这些结果。
- 下一功能阶段 M4：GUI；串口环境可用后补齐 RTU 从站互操作验收。DYN/CSV 离线输入继续暂缓。

## M3.1 TCP 只读从站记录

- 新增 TCP 只读从站，CLI `run` 与 Python `SessionRunner` 共用入口，常量/正弦按独立绝对数据时钟发布快照。
- FC03/04 使用同一份零基 float32 点表；只允许完整点读取，跨空洞/半点返回异常 02，非法数量返回异常 03，其他功能码返回异常 01。
- TCP ADU 与 PDU 编码复用锁定的 PyModbus；有界 selector 适配器检查 MBAP、处理拆包/粘包并保留事务号。最多 16 个连接，每连接收发缓冲各 4096 字节；不完整请求期限为 max(1 秒, timeout_ms)。
- 独立 socket 客户端验证正常读、拒写、地址边界、分帧、事务号、错误站号、畸形 MBAP、数据时钟、停止、端口占用与自然结束。
- 本轮 Windows/Python 3.12 下 56 项测试通过（原有 46 项及新增 10 项）；测试使用工作区临时目录避开沙箱系统临时目录权限限制。
- 本阶段只做本机 TCP 验证，未宣称麒麟、物理串口或实际设备通过；最新状态见顶部。

## M2 RTU 主站记录

- 用户确认的调度标准已实施：默认 10% 可配置容差，容差内正常、超出警告；按周期首发判定，不把读回误报为迟发。应答超时与严格策略的失败条件保持独立。
- 新增容差边界、100/200ms 周期、自定义比例、非法配置、读回隔离和继续运行回归；共 46 项单元测试。此前虚拟串口报告对应容差功能加入前版本，不覆盖本次新增告警判定。

- M1 收尾：SessionRunner、停止、状态机、完整会话摘要和日志失败传播已接入。
- M2：复用 PyModbus 3.11.4 的 PDU/CRC/帧编码，pySerial 3.5 驱动串口；受限适配器负责绝对 deadline、静默和关联证据，详见 [选型记录](pymodbus-evaluation.md)。
- run / ports / validate 可用；常量和正弦、FC16、FC03/04 读回、连续/严格策略、限频重连已实现。
- 43 项单元测试在 Windows、麒麟通过；Windows 虚拟 COM 六组测试通过；麒麟 PTY 首轮出现一次超时，复测六组通过，原始失败记录保留。详见 [验证记录](validation-m2.md)。
- 100ms 性能统计区分周期首发与全部交易；计时基准在初次打开串口之后建立。
- 只验证了虚拟串口与模拟从站，尚无物理 RS485、真实设备、长期运行、GUI 负载下的验收。
- 本阶段记录时从站、GUI/打包和独立交付验收尚待实施；最新状态见文档顶部。

## 模块与复用原则

| 能力 | 实现边界 |
|---|---|
| 协议编码与串口 I/O | 复用 PyModbus 与 pySerial，版本锁定并回归验证 |
| 调度与会话 | 共用绝对槽位、停止、重连和运行策略，不在 CLI/GUI 重复实现 |
| 数据源与映射 | 解码、信号生成、滤波、寄存器编码分离，保留时间和质量语义 |
| 日志与结果 | 通用事件模型、有界异步记录、统计与导出 |
| 界面 | 使用同一应用层接口；核心不依赖界面库 |

## 必须保留的回归

100/200 ms 槽位；35 ms 应答；分段应答；迟到数据重新静默；静默后预算不足；连续噪声有界等待；
CRC 错误、错误地址、Modbus 异常；短写/断线/重连；超时后的 ambiguous；无 flush 50 ms 轮询；
严格回放落后不追赶；坏质量点不伪装好值；完整 float32 原子点；日志拥塞/磁盘失败；UI 不拖慢通信；
停止与资源释放；离线分析与在线协议不同容错；标准设备互操作及数据质量验证。
