# 实施记录

## TCP 重启与有界日志保留修复（2026-10-23）

- POSIX TCP 监听设置 SO_REUSEADDR，允许客户端仍连接时主动停止后立即重启同端口；不启用 SO_REUSEPORT，Windows 保留独占地址策略。
- 日志达到 32 MiB 改为自动分片；logging.max_files 默认 100，可通过 JSON/GUI 配置 1～10000，数量包含当前分片。
- 超限删除最旧片，保持单会话日志文件数量有界；历史淘汰与队列溢出分开计数，原始整场证据标记不完整，但不因此停止通信。
- 原始日志读取支持首片已淘汰的情况；实时 worker 状态不携带完整分片列表，最终摘要保存当前分片索引。
- 旧配置兼容默认保留数量；磁盘创建、写入、刷新、关闭或删除失败仍停止。历史验证记录保留当时的“32 MiB 停止”行为，不代表修复后的策略。
- macOS Apple Silicon / Python 3.12.11 / 锁定依赖下收集 103 项测试，102 项通过、1 项 Windows 原生 DPI 测试跳过；原生 Cocoa GUI/worker 17 项另行复测通过，与全量测试重叠。
- 隔离 PTY 与本机 TCP 的 8 组 CLI/worker 通信矩阵通过，另有原生 Cocoa GUI + PTY 通信通过；四点写入读回各运行 5 秒，CLI、worker、GUI 均完成 50 次 ACK 和 50 次读回。
- 真实 32 MiB 分片阈值写入超过 64 MiB：3277 条事件全部写入、队列丢失为 0，发生两次换片；保留 2 片并淘汰最旧 1 片，剩余序号 1618～3277 连续，正常收尾且明确标记历史截断。
- 新增小文件用例覆盖 1/2/100 片上限、精确大小边界、缺口记录换片，以及创建、短写、刷新、关闭和删除失败；通信会话在历史淘汰后继续运行。完整本机证据位于 `results/fixes-20261023/`（Git 忽略目录）。
- 此轮仅修复 TCP 重启与日志策略；审查中发现的 accept 暂态异常隔离和连续拆包计时问题未在本轮修改。Windows/麒麟未在本轮重新实测，物理串口和长时间稳定性仍需后续验收。

## M4.1 单会话 GUI 实现记录（2026-10-22）

- 可选 PySide6 6.7.2 GUI，支持三种通信模式，常量/正弦配置编辑、JSON 加载/保存、统一校验、串口枚举、结果目录及启停。
- GUI 通过 QProcess 启动独立 Python worker，共用 SessionRunner。运行配置冻结；工作进程退出后恢复编辑，可再次启动。
- worker 使用 schema_version=1 JSONL：stdin 接收 stop；stdout 输出 status/result；stderr 输出启动/意外故障。父进程管道关闭时请求停止。
- 状态最多 5 Hz；事件预览最多 100 条，每条消息最多 300 字符；输出队列容量 2，拥塞替换旧状态并记录预览事件丢失；通信不等待管道。原始日志仍独立写入。
- GUI 最多保留 2000 行；请求停止后最多等待 5 秒再强制结束。崩溃/强制结束标记证据可能不完整并尝试保存 gui-worker-error.json。
- 界面采用统一浅色设计，新增公共主题/控件、配置标签页、状态与关键计数、日志/详细统计，支持窄屏滚动和上下排列。详见 [GUI 设计](gui-design.md)。
- Windows 采用 GDI 字体后端、中文回退、完整字体像素对齐和 Qt 逐显示器缩放；隐藏原生窗口确认 Per-Monitor V2，截图像素与 DPR 一致，控件外部高度为 36 逻辑像素。
- 87 项测试通过，包括 worker 协议、管道背压收尾、自然结束/停止/父进程断开、配置往返、进程启动失败、崩溃恢复、关闭收尾、UI 日志上限、下拉框键盘交互与窄屏访问。另以独立原生进程验证 100%、125%、150%、175%、200% 及本机 300% 缩放；GUI 会话回归使用离屏模式。
- 已从 GUI 启动 TCP 从站，通过独立 socket 客户端读取四个 float32 点并正常停止；检查了 Qt 渲染的初始/运行截图。没有用模拟 UI 图片代替实际渲染。
- 仍待完成：跨显示器拖动/输入法等真实桌面交互验收、GUI 下虚拟/物理串口联调、GUI/日志压力下 100ms 时序对照、麒麟 GUI、分平台安装包与打包自检。M4 整体尚未完成。
- DYN/CSV 离线输入继续暂缓。

## M3.2 RTU 只读从站记录

- RTU/TCP 共用 ReadOnlyRegisters、快照、数据时钟、SessionRunner、停止、日志与摘要。CLI `run` 支持 `rtu-slave`。
- RTU 复用 PyModbus CRC/帧/PDU 编码和既有 pySerial 打开逻辑；接收缓冲 256 字节，按驱动静默划帧，坏 CRC/短帧/超长帧整帧丢弃。
- 广播、其他站号不响应；FC03/04 可读，其他请求功能码异常 01；读数量、空洞和半点检查沿用 TCP 规则。
- 连续策略 I/O 故障/短写至少间隔 1 秒重连；严格策略失败退出。停止支持接收、持续噪声、半帧和重连等待。
- 本轮 Windows/Python 3.12 下 70 项测试通过：包含独立 CRC 固定报文、分段、未知功能码、广播、噪声恢复、四种字节序、正弦、数据时钟、停止和故障策略。测试使用模拟串口与确定性时钟。
- 当前环境未枚举到串口；本轮没有执行虚拟 COM、Linux PTY 或物理 RS485 验收，不以模拟测试代替这些结果。
- 串口环境可用后补齐 RTU 从站互操作验收；最新 GUI 状态见顶部。

## M3.1 TCP 只读从站记录

- 新增 TCP 只读从站，CLI `run` 与 Python `SessionRunner` 共用入口，常量/正弦按独立绝对数据时钟发布快照。
- FC03/04 使用同一份零基 float32 点表；只允许完整点读取，跨空洞/半点返回异常 02，非法数量返回异常 03，其他功能码返回异常 01。
- TCP ADU 与 PDU 编码复用锁定的 PyModbus；有界 selector 适配器检查 MBAP、处理拆包/粘包并保留事务号。最多 16 个连接，每连接收发缓冲各 4096 字节；不完整请求期限为 max(1 秒, timeout_ms)。
- 独立 socket 客户端验证正常读、拒写、地址边界、分帧、事务号、错误站号、畸形 MBAP、数据时钟、停止、端口占用与自然结束。
- 本轮 Windows/Python 3.12 下 56 项测试通过（原有 46 项及新增 10 项）；测试使用工作区临时目录避开沙箱系统临时目录权限限制。
- 本阶段只做本机 TCP 验证，未宣称麒麟、物理串口或实际设备通过；最新状态见顶部。

## 模块与复用原则

| 能力 | 实现边界 |
|---|---|
| 协议编码与串口 I/O | 复用 PyModbus 与 pySerial，版本锁定并回归验证 |
| 调度与会话 | 共用绝对槽位、停止、重连和运行策略，不在 CLI/GUI 重复实现 |
| 数据源与映射 | 解码、信号生成、滤波、寄存器编码分离，保留时间和质量语义 |
| 日志与结果 | 通用事件模型、有界异步记录、统计与导出 |
| 界面 | 使用同一应用层接口；核心不依赖界面库 |

## 必须保留的回归

100/200 ms 槽位；35 ms 应答；分段应答；迟到数据重新静默；静默后预算不足；连续噪声有界等待；
CRC 错误、错误地址、Modbus 异常；短写/断线/重连；超时后的 ambiguous；无 flush 50 ms 轮询；
严格回放落后不追赶；坏质量点不伪装好值；完整 float32 原子点；日志拥塞/磁盘失败；UI 不拖慢通信；
停止与资源释放；离线分析与在线协议不同容错；标准设备互操作及数据质量验证。
