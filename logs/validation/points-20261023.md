# 四测点独立数据与 GUI 设置页验证

日期：2026-10-23。范围：当前工作区源码；不是发布包验收。

## 环境与结果

- macOS 27.0.1 arm64，Python 3.12.11，PySide6 6.7.2，PyModbus 3.11.4。
- `python -m unittest discover -s tests -v`：收集 130 项，通过 129 项，跳过 1 项 Windows 原生 DPI 测试；用时 7.805 秒。
- 原始输出：`results/points-20261023/unittest.log`；精简结果：[summary.json](points-20261023/summary.json)。
- 最初沙箱内 Qt 启动报告缺失 NEON 特性并中止，不能算完整回归。随后在沙箱外以同一虚拟环境执行，最终完整结果如上。

## 覆盖

- 四个点全部启用时独立常量；统一时钟下不同频率、振幅、偏置的混合采样；非地址顺序配置的值与地址关联。
- schema_version=1 共享源展开、旧 JSON 加载、新版序列化往返、拒绝新旧字段混用、各点独立参数边界。
- 禁用点不参与采样、地址占用或线路预算；全部禁用禁止启动；地址重叠提示具体测点。
- 三个设置页归属、数字地址框步进/上界、常量/正弦参数切换、禁用后恢复参数、预留数据源配置保留。
- GUI→实际 worker→回环 TCP 读回不同测点值；配置快照保存版本 2 的各点源参数。
- 独立 TCP 字节对端验证 FC03/04、禁用地址空洞及跨空洞异常；确定性 RTU 对端验证独立值写入/读回与从站波形快照。
- 小屏下四点全启用、常量/正弦混用时逐个滚动到控件；原有停止、故障、日志轮转和工作进程生命周期回归保留。
